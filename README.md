# Поиск бабочек на фотографиях

Задача — находить взрослых бабочек и молей и выделять их прямоугольными рамками. Собрали фотографии iNaturalist с лицензией CC0, организовали разметку в Яндекс Заданиях и независимое ревью. Затем сравнили готовые модели без дообучения.

| Данные | Значение |
| --- | ---: |
| Фотографии | 400 |
| Независимые проверки | 800 |
| Расходы с комиссией | 791,28 ₽ |

## Результаты

Метрики рассчитаны относительно полученной разметки команды.

| Модель | F1@IoU 0,50 | F1@IoU 0,75 | Время, с |
| --- | ---: | ---: | ---: |
| **Qwen3-VL-2B-Instruct** | **0,8872** | **0,6667** | 845,54 |
| Grounding DINO tiny, порог 0,30 | 0,8132 | 0,6520 | 141,97 |
| Grounding DINO tiny, порог 0,20 | 0,6894 | 0,5648 | 141,97 |
| OWLv2 base | 0,6445 | 0,3686 | 186,96 |

Выбрали Qwen: она дала лучший F1. Снижение порога Grounding DINO уменьшило пропуски, но добавило лишних срабатываний и ухудшило результат.
